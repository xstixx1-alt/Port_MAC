# Stocky non Stop — macOS Port

## Установка
1. Скачайте `StockyNonStop_Mac_v2.zip` из [Releases](https://github.com/xstixx1-alt/Port_MAC/releases)
2. Распакуйте
3. Двойной клик на `INSTALL.command`

## Обновление
Двойной клик на `UPDATE.command` — проверит GitHub, скачает и установит новую версию.

## Что внутри
- `config.sh` — настройка репозитория для обновлений
- `INSTALL.command` — установщик (скачивает, ставит зависимости, запускает)
- `UPDATE.command` — апдейтер (проверяет GitHub Releases)
- `version.txt` — текущая версия
